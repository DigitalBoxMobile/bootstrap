# AGENTS.md

Репозиторий подписанных bootstrap-манифестов клиентов Konsierge. Уточняет глобальные инструкции.

- Архитектурные решения — `docs/adr/`; контракт клиента — `docs/client-contract.md` и `testdata/`, меняются вместе с `bootstrap/contract.py`.
- Приватные ключи подписи в репозиторий не попадают ни в каком виде, включая зашифрованный. В `keys/` только публичные JWK.
- `dist/*.jws` меняется только через `bin/sign`; ручная правка подписанных файлов запрещена. `version` в манифесте строго растёт.
- CI не подписывает: он проверяет подпись публичными ключами, схему, монотонность версии и публикует байты без изменений.
- Источник правды и CI — GitHub `DigitalBoxMobile/bootstrap` (ветка `main`, GitHub Actions); GitLab не используется.
- Любой скрипт публикации и проверки должен работать с рабочей машины без CI и без `konsierge.com`.
