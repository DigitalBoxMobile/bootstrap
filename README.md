# bootstrap

Подписанные bootstrap-манифесты для клиентов Konsierge: актуальные базовые домены и адреса сервисов,
которые приложения получают во время работы из нескольких независимых зеркал вместо констант сборки.

Состояние: проектирование. Дизайн — `docs/requests/client-bootstrap-config/design.md`.

Планируемая структура (см. §5 дизайна):

```
manifests/   источник манифестов по окружениям
dist/        подписанные JWS — публикуемые байты
keys/        публичные ключи (JWK), встраиваются в клиенты
schema/      JSON Schema манифеста
mirrors.yml  цели публикации
bin/         sign, verify, publish, check-mirrors
testdata/    тест-векторы для клиентских реализаций
```

Контекст: инцидент DNS 2026-11-02 и предложения по устойчивости — репозиторий `traefik`,
`docs/requests/dns-provider-resilience/`.
