# ADR 0001: Подписанные bootstrap-манифесты из независимых зеркал

- Статус: Принято
- Дата: 2026-11-02

## Контекст

Инцидент DNS 2026-11-02 (репозиторий `traefik`, `docs/requests/dns-provider-resilience/`) показал, что адреса API зашиты
в мобильные сборки: смена или добавление домена требует релиза через сторы. Клиенты — нативные iOS (Swift) и Android (Kotlin),
в основном в РФ. Нужно, чтобы установленные приложения узнавали актуальные базовые домены во время работы, источники не падали
одновременно и были доступны из РФ, а компрометация любого места хранения не позволяла увести трафик.

Не решается: отказ самого API, блокировка всех наших доменов разом, компрометация ключа подписи для уже выпущенных сборок.

## Решение

- **Манифест** на окружение (`production`, `staging`), общий для всех приложений. Содержит только базовые домены
  (`base_domains`, приоритет слева направо); поддомены сервисов знает приложение (`<host>.<base_domain>`), абсолютные URL
  из ответов backend переписываются заменой базового домена. Также: свои зеркала, таймауты `policy`, `min_app_version`, `notice`.
  Формат v1 расширяется только совместимо (клиент игнорирует незнакомые поля); несовместимое — новый путь `/v2/`.
- **Подпись**: один файл JWS General JSON Serialization, `alg: EdDSA` (Ed25519), подписываются байты payload — канонизация JSON
  не нужна, несколько подписей в одном файле дают ротацию и будущий порог. Проверка реализуема без JOSE-библиотеки.
- **Ключи**: офлайн у владельца, файлы `age` с парольной фразой, копия в Passbolt и две офлайн-копии, без аппаратного токена.
  В сборке два prod-ключа (активный и запасной) и отдельный staging-ключ; prod-сборки не доверяют staging-ключам. CI ключей
  подписи не имеет: компрометация GitLab равна компрометации зеркала.
- **Целостность на клиенте**: хотя бы одна верная подпись доверенного ключа, `env` совпадает со сборкой, `version` не ниже
  сохранённой в защищённом хранилище (защита от отката и «замороженного» зеркала), из всех валидных ответов берётся максимальная
  версия. Срок `expires_at` мягкий: просроченный манифест используется, жёсткий срок превратил бы нашу забывчивость в отказ всех клиентов.
- **Зеркала** первой итерации: Yandex Object Storage, Selectel Object Storage, GitHub raw (`konsierge/bootstrap`),
  `bootstrap.ai-konsierge.ru` как CNAME на бакет. Содержимое подписано, поэтому зеркалу не нужно доверие. Сборка содержит
  последний подписанный манифест как встроенный.
- **Источник правды** — этот репозиторий (GitLab `digitalbox/backend/instruments/bootstrap`, зеркало GitHub `konsierge/bootstrap`);
  публикация байт в байт, работает с рабочей машины без GitLab и без `konsierge.com`; внешний монитор сверяет зеркала с `dist/`.
- **Certificate pinning** в сборках не вводится (подтверждено мобильной командой): системное доверие и Certificate Transparency
  достаточны, пиннинг заблокировал бы резервный домен и смену CA. Если понадобится — только через манифест (`tls.spki_pins`, fail-open).

## Последствия

- Смена порядка или добавление домена — правка, подпись, публикация (минуты), без релиза. Отказ всех зеркал не критичен:
  список доменов уже в кеше или сборке, клиент переключается без сети к зеркалам.
- Остаточный риск: при компрометации prod-ключа сборки, где он в доверенном наборе, уязвимы до обновления (запасной ключ + релиз,
  `min_app_version`). Отзыв без релиза требует TUF-подобного корня — отдельное решение при росте числа подписантов.
- Операционные обязанности: домены из любого манифеста за последние 3 года продлеваются (исключение домена — отдельный осознанный шаг
  с бампом версии); переподпись до истечения `expires_at` (алерт за 60 дней); `version` строго растёт.
- Зеркала и их пользователи видят IP и факт использования приложения; GitHub — зарубежная юрисдикция. Содержимое манифеста публично.

## Альтернативы

| Вариант | Почему нет |
| --- | --- |
| Sigstore/cosign keyless | онлайн-зависимость от Fulcio/Rekor за рубежом; избыточно для файла в 3 КБ |
| Полный TUF | правильная модель, но 4 метафайла и клиентская библиотека на платформу; взяты свойства (монотонность, срок, набор ключей), не формат |
| minisign / signify, SSH-подписи | нет мобильных библиотек, формат из двух файлов |
| ECDSA P-256 | работает, но Ed25519 детерминирован, короче, без проблем с nonce |
| Только TLS зеркал | зеркало или его CDN может подменить содержимое |
| Пара `json` + отдельная подпись | рассинхрон версий между зеркалами |
| Жёсткий срок манифеста | превращает забытую переподпись в отказ всех клиентов; заморозка уже отсечена монотонностью |
| Полные URL сервисов в манифесте | дублирует знание приложения; отложено до потребности менять адрес вне схемы `<host>.<base_domain>` |
| Telegram-канал, Cloudflare R2/Workers, IPFS-шлюзы | нестабильная доступность из РФ, API-ключ в клиенте, латентность |
| DNS TXT как основной канал | размер, фильтрация резолверов; годится только как указатель |
| CDN перед бакетами | не нужен при объёме ~1 ГБ/день суммарно |
